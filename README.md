# Markit

AI-powered market entry, opportunity discovery, lead intelligence, and personalized sales outreach.

A three-hour hackathon MVP built with Next.js, TypeScript, Tailwind CSS, shadcn/ui, OpenAI SDK, Convex, Vercel, Crustdata API, Zod, and Vitest.
