# Documentation

Keep documentation small and useful for implementation and handoff.

- [Decisions](decisions.md): date, decision, rationale, and consequence.
- [Progress](progress.md): current status, completed work, blockers, and next action.
- [Setup](setup.md): local development, integration configuration, and Vercel deployment notes.
- [Product context](../context/README.md): brief, constraints, and assumptions.
- [Audit log](../audit/README.md): verification evidence and known limitations.

Add setup, architecture, or integration notes when the implementation makes them concrete. Avoid speculative documentation.
